# MyStyle AI

AI хувийн стилист — хэрэглэгчийн биеийн онцлог, нүүрний хэлбэр, арьсны өнгөнд тулгуурлан
хувцас, өнгө, үсний засалтын зөвлөгөө гаргадаг веб апп.

## Юу багтсан бэ

- Стилийн тест (quiz)
- Selfie зураг оруулах боломж (AI зургаас нүүрний хэлбэр уншина)
- AI-аар үүсгэсэн хувийн тайлан: тохирох хэлбэр, өнгөний palette, үсний засалт, outfit санаа
- Улаанбаатарын улирлаар өнөөдрийн хувцасны санал
- PDF татах
- Premium түгжээ (худалдан авалтын зөвлөмж) — мөнгө төлөх сонирхлыг шалгах хэсэг

---

## 1. Юу хэрэгтэй вэ

- **Node.js 20.6 ба түүнээс дээш** (`node -v` гэж шалгана)
- **Anthropic API key** — https://console.anthropic.com → API Keys.
  Анхаар: API дуудалт бүр мөнгөтэй. Эхэндээ бага лимит/budget тавь.

## 2. Локал дээр ажиллуулах

```bash
# 1. Хамаарал суулгах
npm install

# 2. .env үүсгэх
cp .env.example .env
# дараа нь .env-г нээж ANTHROPIC_API_KEY=... -ээ бөглө

# 3. Ажиллуулах
npm start
```

Дараа нь browser дээр http://localhost:3000 нээ.

## 3. Интернэтэд гаргах (deploy)

Хамгийн хялбар хувилбарууд (бүгд үнэгүй tier-тэй):

### Render.com
1. Кодоо GitHub-д push хий (`.env`-г **бүү** push хий — `.gitignore` дотор байгаа).
2. Render дээр New → Web Service → GitHub repo-гоо сонго.
3. Build command: `npm install` · Start command: `npm start`
4. Environment → `ANTHROPIC_API_KEY`-ээ нэм.

### Railway.app эсвэл Fly.io — мөн адил: repo холбоод env variable нэмнэ.

> **Чухал:** API key-г зөвхөн серверийн environment variable-д тавина.
> Frontend код (index.html) дотор хэзээ ч бүү тавь — нийтэд ил болж, мөнгийг чинь зарцуулна.

## 4. Загвар (model) сонгох

`.env` дотор `MYSTYLE_MODEL`-оор удирдана:
- `claude-sonnet-4-6` — чанар сайтай (default)
- `claude-haiku-4-5-20251001` — хямд, хурдан (туршилтын үед тохиромжтой)

## Дараагийн алхмууд (validate хийсний дараа)

1. **Хэрэглээ хэмжих** — Premium товч хэдэн хүн дарж байгааг сервер дээр тоол
   (server.js дотор `/api/track` endpoint нэмж болно).
2. **Жинхэнэ төлбөр** — QPay / Storepay / SocialPay холболт нэмэх.
3. **Хэрэглэгчийн бүртгэл** — тайлангаа хадгалах бол database (жишээ нь Postgres).
4. **Зураг хадгалалт** — одоогоор selfie зургийг хадгалдаггүй (privacy-д сайн).
   Хэрэв хадгалах бол хэрэглэгчээс зөвшөөрөл аваад, аюулгүй storage ашигла.

## Анхаарах эрх зүй / ёс зүй

- Selfie зураг боловсруулдаг тул privacy policy бичих хэрэгтэй.
- Зөвлөгөө нь эерэг framing-тэй байхаар prompt-д суулгасан. Үүнийг бүү өөрчил —
  body image-ийн эмзэг асуудлаас сэргийлнэ.
